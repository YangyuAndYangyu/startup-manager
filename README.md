# 开机启动管理器 v2.1

把你电脑上所有「开机自启」的东西一次看清，然后一键收拾干净 —— 支持**禁用 / 启用 / 删除**，
还可以自动挑出「无效项、更新器、可疑项」让你一键清理。全部操作都能一键撤销，绝不误删。

## 直接双击就能用（推荐）

- 桌面快捷方式：**开机启动管理器**（刚帮你建好了）
- 或者直接双击：`dist\开机启动管理器.exe`

它是单个 exe（约 10 MB），**不用装 Python、不用管理员权限**（个别操作需要管理员时软件会提示并自动重开）。

> 为什么推荐 exe 而不是脚本？
> 微软商店版 Python 会把 `%LOCALAPPDATA%` 的写入重定向到软件包私有目录，
> 备份区会"藏"到别处；exe 是普通程序，备份区固定为 `%LOCALAPPDATA%\StartupManager`。
> 第一次运行 exe 时，它会**自动把旧脚本记录下的禁用项搬进正式备份区**，不会丢数据。

## 它能管哪些自启位置

| 来源 | 位置 |
| --- | --- |
| 当前用户 Run / RunOnce | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run(Once)` |
| 所有用户 Run / RunOnce | `HKLM\Software\Microsoft\Windows\CurrentVersion\Run(Once)`（含 32 位视图） |
| 当前 / 所有用户 启动文件夹 | `%APPDATA%...\Startup` 与 `%ProgramData%...\Startup` |
| 计划任务 | 触发条件为「登录时 / 开机时」的任务（微软自带的默认隐藏，可勾选显示） |

> Windows **服务**不在此管理范围内（缺了系统服务容易出事）。
> 常规排查「任务管理器 → 启动应用」看不到的部分（注册表 RunOnce、计划任务、32 位视图），本工具都能看到。

## 界面操作

- 顶部：**✨ 一键优化**、**↻ 重新扫描**、**🛡 权限状态**
- 统计卡片可点击筛选；搜索框支持名称/命令/路径；点表头可排序
- 左侧列表：🟢 正常、灰色=已禁用、🔴 无效项/可疑；前面 6 个筛选胶囊一键切换
- **按软件分组**：顶部勾选后列表按软件合并，某软件名旁有「整组」标签，点它右侧出现整组概览
- 选中后右侧显示详情：分类、建议、完整命令行、目标文件状态和大小的都一目了然
- 操作按钮：**⛔ 禁用所选 / ✅ 启用所选 / 🗑 删除所选 / ➕ 新增 / ↩ 撤销 / 📈 对比报告 / 💾 导出**
- 双击一行 = 打开文件位置；右键 = 更多操作

## 安全性

- 「禁用」= 把启动项搬进备份区：注册表项连**原值、原类型**一起存进
  `%LOCALAPPDATA%\StartupManager\disabled.json`，启动文件夹文件移到 `disabled_files\`，
  计划任务记住原名后置为禁用 —— 随时一键原样还原
- 每次操作都写进 `%LOCALAPPDATA%\StartupManager\log.txt`
- 「删除」不可撤销，需要二次确认（一般用「禁用」就够了）
- 误禁了系统组件？`ctfmon`（输入法）、`RtkAudUService`（声卡）这类会被标记为「建议保留」，小心别动

## 需要管理员权限的场景

改 HKLM（所有用户）、所有用户启动文件夹、`\Microsoft\` 计划任务时需要管理员。
非管理员下执行这些操作会弹出提示，点🛡按钮一键提权重启。

## 命令行（脚本模式）

```bat
python startup_manager.py --list          :: 文本列出全部启动项
python startup_manager.py --enable-all    :: 还原所有被本软件禁用过的项
```

## 报告数据存在哪

每个操作（禁用/启用/一键优化）后都在 `%LOCALAPPDATA%\StartupManager\history.json`
记一条快照：自启总数、各分类数量、时间。报告页面就是拿这些快照做对比的。

## 重新打包 exe

```bat
打包exe.bat        :: 一键重新打包（会自动装 PyInstaller、生成图标、带版本信息）
```

或手动：`pyinstaller --noconfirm --clean --onefile --windowed --name 开机启动管理器 --icon egg.ico --version-file version_info.txt startup_manager.py`
